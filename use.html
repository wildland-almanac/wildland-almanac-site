Bring it into your tools

The data are Cloud-Optimized GeoTIFFs (COGs) on Source Cooperative. You can stream them directly into ArcGIS Pro, QGIS, Earth Engine, or any GDAL-based tool — reading only the pixels you need, with no download. When you do want files on disk, every layer is a public URL or a one-line bulk copy.

How the data are organized read this first

The Almanac is published as two dataset roots — California and CONUS — each containing versioned releases. A version is a directory level (v2026.1), not part of the filename. The README and documentation live at each dataset root and describe the release.

# Source organization → dataset root → version → property → file
source.coop/wildland-almanac/
└── california/        # dataset root
    ├── README.md                       # start here
    ├── WildlandAlmanac_CA_Documentation.pdf
    └── v2026.1/                         # a release
        ├── Carbon_AGB/
        │   ├── WildlandAlmanac_CA_Carbon_AGB_1985.tif
        │   ├── … (water years 1985–2025)
        │   └── WildlandAlmanac_CA_Carbon_AGB_2025.tif
        ├── Veg_TreeFrac/
        └── … (19 properties)

Filenames follow WildlandAlmanac_CA_{Property}_{WaterYear}.tif. Substitute the property name and four-digit water year for any other file. Newer releases (v2027.1, …) add as parallel version directories; the older ones stay put so published links keep working.

Read the documentation before quantitative work. Several layers use specific scaling conventions — vegetation fractions are ×10,000, canopy height is in cm, the Fire_LCP file is an 8-band FARSITE raster with its own no-data convention. The documentation PDF at the dataset root is the binding reference.

1 · Stream it most common — no download

Because the files are COGs, GIS tools can read them straight from cloud storage over HTTP, transferring only the bytes needed for your current view and zoom. The URI form differs between ArcGIS Pro and the open-source / GDAL stack — both point at the same underlying file.

ArcGIS Pro
s3://us-west-2.opendata.source.coop/wildland-almanac/california/v2026.1/Carbon_AGB/WildlandAlmanac_CA_Carbon_AGB_2025.tif
QGIS · GDAL · rasterio · terra
/vsicurl/https://data.source.coop/wildland-almanac/california/v2026.1/Carbon_AGB/WildlandAlmanac_CA_Carbon_AGB_2025.tif

On any Source file-detail page, the Cloud URI is the S3 form (for ArcGIS) and the Source URL is the HTTPS form — prepend /vsicurl/ to the latter for GDAL-based tools.

ArcGIS Pro

Add Data → From Path → paste the s3:// URI above. The raster streams in; no download, no credentials.

QGIS

Layer → Add Layer → Add Raster Layer → set Source type to a protocol/HTTP source and paste the /vsicurl/https://… URI.

Python (rasterio)

import rasterio

url = ("/vsicurl/https://data.source.coop/wildland-almanac/"
       "california/v2026.1/Carbon_AGB/"
       "WildlandAlmanac_CA_Carbon_AGB_2025.tif")

with rasterio.open(url) as src:
    # windowed read — only the bytes you need are fetched
    window = src.window(*src.bounds)  # or a sub-bbox
    agb = src.read(1, window=window)
    print(src.crs, src.res, agb.shape)

R (terra)

library(terra)

url <- paste0("/vsicurl/https://data.source.coop/wildland-almanac/",
              "california/v2026.1/Carbon_AGB/",
              "WildlandAlmanac_CA_Carbon_AGB_2025.tif")

agb <- rast(url)
agb            # prints extent, CRS (EPSG:5070), resolution
plot(agb)
Projection. All layers are EPSG:5070 (NAD83 / CONUS Albers), 30 m, co-registered to sub-pixel precision — treat the 19 properties as a single stack. No-data is −9999 for all layers except Fire_LCP, where it is 0 (FARSITE convention).

2 · Download one file simple · HTTPS

Every file has a public HTTPS URL. No credentials needed. Use a browser, curl, wget, or PowerShell Invoke-WebRequest.

# curl / wget
curl -O https://data.source.coop/wildland-almanac/california/v2026.1/Carbon_AGB/WildlandAlmanac_CA_Carbon_AGB_2025.tif

# Windows PowerShell
Invoke-WebRequest -Uri "https://data.source.coop/wildland-almanac/california/v2026.1/Carbon_AGB/WildlandAlmanac_CA_Carbon_AGB_2025.tif" -OutFile "Carbon_AGB_2025.tif"

3 · Bulk download at scale · AWS CLI

For multiple files or whole layer directories, the AWS CLI is fastest. No AWS account or credentials are required — pass --no-sign-request. The CLI is available for Windows, Mac, and Linux at aws.amazon.com/cli.

# one file
aws s3 cp \
  s3://us-west-2.opendata.source.coop/wildland-almanac/california/v2026.1/Carbon_AGB/WildlandAlmanac_CA_Carbon_AGB_2025.tif . \
  --no-sign-request

# one layer directory (all water years)
aws s3 sync \
  s3://us-west-2.opendata.source.coop/wildland-almanac/california/v2026.1/Carbon_AGB/ \
  ./Carbon_AGB/ --no-sign-request

# an entire release
aws s3 sync \
  s3://us-west-2.opendata.source.coop/wildland-almanac/california/v2026.1/ \
  ./wildland-almanac-ca-v2026.1/ --no-sign-request
A note on scale. The full California release is large (hundreds of GB across all 19 layers × 41 years; CONUS will be multiple TB). For most uses, streaming a windowed read is faster and lighter than bulk download. Reach for the CLI when you genuinely need whole layers offline.
